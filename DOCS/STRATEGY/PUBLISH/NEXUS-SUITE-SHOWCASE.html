What's inside every theme
🔍
5-Stage Commission Detection
Account UUID → description keywords → line item keywords → small-price heuristic → custom field key. Automatically identifies commission invoices.
💱
PKR ↔ AED Auto-Switch
Division UUID, UAE address keywords, and exchange rate fields trigger full currency mode — title, tagline, footer, and amount-in-words all switch automatically.
📊
Dynamic Column Logic
Commission mode activates a 6-column table: Unit/Property · Buyer/Client · Sales Date · Deal Value · COM% · Commission. Regular mode shows standard 4-column layout.
🔴
WHT Red Highlight
Withholding Tax rows are automatically detected and rendered in red — zero configuration needed.
🔤
Amount in Words
PKR uses South Asian system (Lakh/Crore). AED uses Western system (Million/Billion). Three-path fallback engine.
🖨️
Print-Safe Layout
A4 page sizing, fixed credit footer, no blank exports. Works in Manager.io Cloud PDF generation without any adjustments.
