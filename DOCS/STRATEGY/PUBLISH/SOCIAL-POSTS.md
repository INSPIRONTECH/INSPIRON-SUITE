Hello Manager.io community,

As an Official Manager.io Advisor working with clients across Bangladesh, Pakistan, and the UAE, I frequently help set up professional invoicing for multi-division businesses — especially those handling commission-based real estate transactions in both PKR and AED.

I kept rebuilding the same logic for different clients. So I packaged it as a reusable suite.

---

**What it does:**

- Automatically detects whether an invoice is a commission invoice (5-stage detection: account UUID → description keywords → line item keywords → price heuristic → custom field key)
- Switches between PKR (Karachi) and AED (Dubai) mode — title, tagline, footer, and amount-in-words all adapt automatically
- Commission mode activates a 6-column layout: Unit/Property · Buyer/Client · Sales Date · Deal Value (PKR/AED) · COM% · Commission
- COM% auto-formats from raw decimal (e.g. `0.0325` → `3.25%`)
- WHT (Withholding Tax) rows are detected and highlighted in red automatically
- Amount in words: South Asian system (Lakh/Crore) for PKR, Western (Million/Billion) for AED
- Print-safe: A4 layout, fixed footer, tested in Manager.io Cloud
