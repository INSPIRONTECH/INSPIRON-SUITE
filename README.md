## Overview

**INSPIRON Suite** is an institutional-grade suite of document themes, executive dashboards, and statutory localization extensions for [Manager.io](https://www.manager.io).

All themes and extensions are built with strict adherence to Manager.io’s sandboxed iframe security architecture, zero-external-CDN tracking, and the official `/api4/view-v1` schema.
