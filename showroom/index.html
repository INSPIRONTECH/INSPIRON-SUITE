Installation Protocol
Zero Friction Setup Inside Manager.io

No complex builds. No external code execution. Choose between 1-Click Alfabase injection or native Manager.io Settings.

1
Open Settings → Custom Buttons
In Manager.io, go to Settings → Custom Buttons and click New Custom Button.
2
Configure Endpoint URL
Set Source to Url, enter https://suite.inspiron.tech/dashboard and set Placement to /summary-view.
3
Click Create — Done
Click Create. The button appears on your Summary page immediately. Click it to open the Executive Dashboard.
4
Or Browse on Alfabase
Visit Alfabase Gallery to browse verified community extensions and themes with instant 1-click install.
