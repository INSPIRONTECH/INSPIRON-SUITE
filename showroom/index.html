Quick Install
3 steps inside Manager.io

No downloads. No builds. Paste a URL and you're live.

1
Open Settings → Custom Buttons
In Manager.io, go to Settings → Custom Buttons and click New Custom Button.
2
Set Source = URL
Set Source to Url, paste the extension endpoint (e.g. suite.inspiron.tech/dashboard) and set Placement to /summary-view.
3
Click Create — Done
Click Create. The button appears on your Summary page instantly. Click it to open the Executive Dashboard in a slide-over panel.
4
Or browse on Alfabase
Find the extension on extensions.alfabase.com — copy the URL shown and paste it into Manager.io Settings → Custom Buttons.
